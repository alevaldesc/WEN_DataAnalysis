# Códigos por tema · Python

Esta carpeta contiene los códigos de los estudios concretos. Todavía no hay
estudios incorporados: cada tema nuevo tendrá su propia subcarpeta.

Por ejemplo: `mercado_laboral_mujeres/01_cargar_limpiar.py`.
Los nombres de tema son ilustrativos.

Para empezar, copia los archivos de [Template](../0_Recursos/Template) a la
carpeta de tu tema y usa [README_tema.md](../0_Recursos/README_tema.md) para
explicar sus datos, objetivo y orden de ejecución.

Los templates y ejemplos se guardan en `0_Recursos`. Los datos y resultados
se mantienen en Drive u otra carpeta externa.
